Model-free：没有显式模型时

model-free 并不等于“没有 MDP”。交互仍可由未知 MDP 产生；只是算法不知道或不使用显式的 (p) 与 (R)，只能从轨迹样本学习。

Monte Carlo：等回合结束再学习

Monte Carlo（MC）用完整回合的实际回报 (G_t) 作为价值目标。例如 first-visit MC 只更新一个回合中状态的第一次出现：

特点：

  • 不需要环境模型；
  • 不 bootstrap，目标来自真实后续奖励；
  • 通常要等回合结束；
  • 目标无 bootstrap 偏差，但方差较高；
  • 对自然终止的 episodic task 最直接。

控制问题还需要探索，例如使用 ()-greedy 策略估计动作价值。

Temporal Difference：走一步就更新

TD(0) 用一步奖励和下一状态当前估计构造目标：

与 MC 相比，TD：

  • 无需模型；
  • 无需等回合结束；
  • 使用 bootstrap，方差通常更低，但目标带有当前估计的偏差；
  • 可用于持续任务。

MC 与 TD 都是 model-free prediction；区别不在于是否有策略，而在于学习目标是否 bootstrap、何时可获得。

Gymnasium 的当前 API

Gymnasium 是维护中的 Gym 分支。当前接口为：

  • terminated：到达 MDP 自身定义的终止状态；
  • truncated：因时间上限等 MDP 外部条件结束当前回合；
  • 两者任一为真都需要 reset，但 bootstrap 处理不同。

方法对比

  • DP：有模型，对所有后继求期望，可做规划。
  • MC：无模型，用完整实际回报，不 bootstrap。
  • TD(0)：无模型，用一步样本和下一状态估计 bootstrap。
  • Q-learning：无模型、off-policy 的 TD 控制，目标对下一状态动作取最大值。

“model-free”只表示不依赖显式环境模型，不表示不需要状态、动作、奖励和转移样本，也不表示算法一定是深度强化学习。
