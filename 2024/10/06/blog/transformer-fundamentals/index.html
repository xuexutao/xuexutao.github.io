Transformer 的核心思路

Transformer 是一种用注意力处理序列的架构。原始论文面向机器翻译，使用 encoder–decoder；今天常见的 BERT、GPT 和 T5 分别保留了其中不同部分。

与 RNN 相比，自注意力可以在训练时并行处理同一层的所有 token；与固定卷积核相比，每个位置能直接聚合任意位置的信息。代价是标准注意力需要构造长度平方级的分数矩阵。

一个完整 Transformer 不只有 attention，还包括：

  • token embedding 与位置信息；
  • Query、Key、Value 投影；
  • scaled dot-product attention；
  • multi-head attention；
  • padding mask 与 causal mask；
  • residual connection、LayerNorm；
  • position-wise feed-forward network（FFN）；
  • encoder self-attention、decoder masked self-attention 和 cross-attention。

Padding mask

同一 batch 中的句子通常被补齐到相同长度。padding token 不能成为有效 Key，否则真实 token 会把注意力分给无意义位置。padding Query 对应的输出通常在后续 loss 中一并忽略。

Encoder 与 Decoder

Encoder layer

每层依次包含：

  1. 无因果遮罩的 multi-head self-attention；
  2. residual + LayerNorm；
  3. position-wise FFN；
  4. residual + LayerNorm。

多层堆叠后，输出仍为 ([B,L_s,d_{}])，可作为分类特征，也可供 decoder 做 cross-attention。

Decoder layer

原始 encoder–decoder Transformer 的每层包含：

  1. 带 causal mask 的 decoder self-attention；
  2. 对 encoder 输出的 cross-attention；
  3. FFN；
  4. 每个子层外的 residual + LayerNorm。

cross-attention 的维度关系是：

  • Query 长度 (L_t)：目标序列长度；
  • Key/Value 长度 (L_s)：源序列长度；
  • 输出长度仍为 (L_t)。

最后用线性层把 decoder 隐状态投影到词表 logits。

三类预训练模型

BERT：encoder-only

BERT 堆叠双向 Transformer encoder。每个非 padding token 可以访问左右上下文。原始预训练以 masked language modeling（MLM）为主，并包含 next sentence prediction；后续 encoder 模型未必保留 NSP。

适合：

  • 文本分类；
  • 序列标注与命名实体识别；
  • 抽取式问答；
  • 生成句向量或 token 表示。

GPT：decoder-only

GPT 堆叠带 causal mask 的 Transformer decoder block，通常没有 encoder–decoder cross-attention。训练目标是下一个 token 的条件概率：

适合开放式生成，也可以把分类、问答等任务序列化成文本生成。

T5：encoder–decoder

T5 保留 encoder 和 decoder，并把所有任务统一为 text-to-text。原始 T5 预训练使用 span corruption：encoder 读取带哨兵标记的损坏文本，decoder 自回归生成被删去的文本片段。

适合：

  • 翻译；
  • 摘要；
  • 条件生成；
  • 输入与输出都是文本的统一多任务学习。

训练与推理不能混为一谈

Encoder-only

训练时对被遮盖 token 做交叉熵，或在下游任务上对分类头做有监督微调。推理通常一次前向完成，没有逐 token 解码。

Decoder-only

训练时将完整序列右移一位构造输入与标签，并用 causal mask 并行计算所有位置的 next-token loss。标签仍来自同一条序列的下一 token，不能把不同句子机械拼接后制造跨句目标。

推理时则真正自回归：

  1. 输入已有前缀；
  2. 得到下一个 token 的 logits；
  3. 用 greedy、beam search 或随机采样选 token；
  4. 把新 token 追加到前缀并重复。

KV cache 保存历史层的 Key/Value，避免每一步重新计算整个前缀，但不会消除新 token 对历史 Key 的注意力开销。

Encoder–decoder

训练时 encoder 处理完整源序列，decoder 用右移后的目标序列做 teacher forcing。推理时 encoder 通常只运行一次，decoder 借助 self-attention KV cache 和固定的 encoder 表示逐 token 生成。

常见误区

  • Embedding 不是 one-hot 经过手写两层线性网络的必要结果：nn.Embedding 直接学习词表矩阵，索引等价于选取对应行。
  • Self-attention 不等于 Q、K、V 数值完全相同：它们来源相同，但经过不同投影。
  • decoder-only 不等于原始 Transformer decoder：现代 GPT block 通常没有 cross-attention。
  • mask 的布尔含义不是所有 PyTorch API 都相同：必须查看所调用函数的文档。
  • 训练可并行不代表生成可并行：causal LM 的 teacher forcing 训练能并行，未知输出的自回归推理仍有顺序依赖。
  • 注意力权重不是可靠解释的充分证据：它只是一次前向中的归一化混合系数。

复杂度与局限

标准 self-attention 的分数矩阵为 (LL)，时间和显存通常随序列长度呈 (O(L^2)) 增长。长上下文模型会采用稀疏注意力、滑动窗口、分块、低秩近似或更高效的精确 kernel，但这些优化不能被简单概括为“Transformer 已经是线性复杂度”。

此外，Transformer 本身只定义架构和条件分布，不保证事实正确、鲁棒推理或无限上下文记忆；数据、目标函数、解码策略和系统约束同样重要。
