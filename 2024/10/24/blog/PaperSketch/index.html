阅读方式

这篇文章以原始 3D Gaussian Splatting（3DGS）为坐标系，按同一模板整理后续工作：

  1. 要解决的问题：它修改了表示、优化、SLAM 系统，还是光栅化器？
  2. 核心贡献：相对 3DGS 新增了什么。
  3. 关键机制：只保留理解方法所需的公式与流程。
  4. 局限：方法没有解决什么，以及代价落在哪里。

这些论文并非一条单线演进路线。例如，2DGS 与 3D-HGS 修改场景基元，Pixel-GS 与 Spectral-GS 修改致密化，StopThePop、FlashGS 和 WSR 则主要修改渲染器；不能把它们当成同一模块的互相替代品。

基线：3D Gaussian Splatting

要解决的问题

NeRF 的连续体渲染质量高，但逐射线密集查询网络的代价较大。3DGS 改用一组可显式光栅化的各向异性 3D 高斯，在保持可微优化的同时实现实时新视角合成。

局限

  • 投影和按高斯中心近似排序并不等于逐像素精确可见性。
  • 致密化依赖位置梯度与启发式阈值，可能漏掉大而细长的错误高斯。
  • 屏幕空间膨胀和缺少频率约束会在改变分辨率或焦距时产生混叠。
  • SfM 初始化、静态场景与已知相机位姿仍是典型前提。

论文：3D Gaussian Splatting for Real-Time Radiance Field Rendering（SIGGRAPH 2023）

2DGS：用二维盘元表示表面

要解决的问题

3D 高斯是体基元，同一高斯从不同视角投影后不一定对应同一表面位置，因此渲染质量好并不自动意味着几何准确。2D Gaussian Splatting（2DGS）把基元压缩为有朝向的二维椭圆盘元，使几何直接落在一张局部切平面上。

核心贡献

二维高斯由中心 ()、两条切向轴、两个尺度和法向共同定义。在局部坐标 ((u,v)) 中，

渲染时不是把三维协方差仿射近似到屏幕，而是求像素射线与盘元平面的交点，再在交点的局部 ((u,v)) 坐标上计算高斯值。这一 ray-splat intersection 提供透视正确的投影。训练还加入：

  • 深度畸变损失：抑制同一射线上贡献高斯的深度分散；
  • 法向一致性损失：让盘元法向与渲染深度导出的法向一致；
  • 表面提取：可从训练后的盘元和深度图进一步融合网格。

局限

2DGS 更适合近似表面，而非真正具有厚度的半透明介质；遮挡边界、薄结构和低纹理区域仍依赖多视角约束与正则项。几何质量提升也不代表相机位姿误差会被自动修复。

论文：2D Gaussian Splatting for Geometrically Accurate Radiance Fields（SIGGRAPH 2024）

Pixel-GS：按像素覆盖重写致密化信号

要解决的问题

原始 3DGS 用各可见视角中屏幕位置梯度的平均值决定克隆或分裂。一个大高斯可能在很多视角只以边缘参与渲染，平均梯度因此被稀释，导致初始点稀疏区域迟迟不增密；近相机高斯又会因覆盖像素过多而形成漂浮物。

GS-SLAM：把高斯地图用于在线跟踪与建图

要解决的问题

离线 3DGS 假设相机位姿已经由 SfM 求得。GS-SLAM 将 3D 高斯作为在线 RGB-D SLAM 地图，通过可微 RGB-D 重渲染同时支持相机跟踪、地图扩展和新视角渲染。

核心贡献

  • 跟踪：固定当前高斯地图，以渲染颜色与输入 RGB 之间的 L1 误差优化相机位姿；深度观测用于筛选贴近场景表面的可靠高斯，再由粗到细地细化位姿。
  • 建图：依据新观测自适应添加高斯，同时删除噪声高斯；这与离线 3DGS 只围绕已有 SfM 点致密化的目标不同。
  • 统一表示：跟踪与建图共享显式高斯地图，避免逐射线查询隐式网络。

这里容易混淆两篇 CVPR 2024 工作：Yan 等人的 GS-SLAM: Dense Visual SLAM with 3D Gaussian Splatting 主要面向 RGB-D；Matsuki 等人的 Gaussian Splatting SLAM（MonoGS） 首先强调纯 3DGS 表示下的单目 SLAM。本站已有的下图展示的是后者的 tracking–keyframing–mapping 流程，并不是 GS-SLAM 论文原图。

局限

GS-SLAM 依赖深度输入与静态场景假设；位姿漂移、回环、动态物体和大规模长期地图管理仍需额外系统模块。把渲染损失降下来也不等价于得到全局一致的几何。

论文：GS-SLAM: Dense Visual SLAM with 3D Gaussian Splatting（CVPR 2024）

Mip-Splatting：对尺度变化做抗混叠

要解决的问题

原始 3DGS 没有限制三维表示的最高空间频率，并用固定屏幕空间膨胀避免投影高斯小于一个像素。改变焦距、相机距离或输出分辨率时，这会分别造成高频伪影、膨胀和侵蚀。

核心贡献

Mip-Splatting 有两个互补滤波器：

  1. 3D smoothing filter：根据训练视角产生的最大采样频率，为过小的 3D 高斯加入最小尺度约束，先在场景空间限制高频。
  2. 2D Mip filter：用一个二维高斯近似相机像素的一像素 box filter，取代原始的固定膨胀。

局限

滤波以训练视图可见的采样率为依据，无法恢复从未观测到的真实高频细节；较强的带限也可能牺牲锐度。它解决的是采样一致性，不是表面几何或深度排序。

论文：Mip-Splatting: Alias-free 3D Gaussian Splatting（CVPR 2024）

Spectral-GS：让致密化感知高斯形状

要解决的问题

原始致密化主要看位置梯度和最大尺度。一个“针状”高斯可能位置梯度很小，却用极端各向异性过拟合高频纹理，因此不会被及时分裂。Spectral-GS 直接分析协方差谱。

Spectral-GS 用低谱熵触发 3D shape-aware splitting，沿主要轴进行非均匀缩放，使分裂后的混合分布尽量逼近原分布并提高谱熵；同时提出 2D view-consistent filtering，避免固定屏幕滤波在视角变化时进一步放大各向异性。

局限

谱统计比单一最大尺度更有信息，但仍需要阈值和分裂策略；它不能凭空补足未观测几何。额外的谱分析和形状约束也会增加训练实现复杂度。

StopThePop：保留排序，但把排序做到像素级

要解决的问题

原始光栅化器按高斯中心深度在 tile 内排序。同一高斯覆盖的不同像素实际上对应不同的最优射线深度；相机旋转时，中心深度次序可能突然交换，从而产生 popping 和视角不一致。

它没有取消排序，而是用更复杂的层次队列换取一致性；性能取决于局部深度复杂度和 GPU 实现。场景表示中的漂浮物或错误几何也不会因精确排序自动消失。

FlashGS：减少无效 tile–Gaussian 工作

要解决的问题

在大场景和高分辨率下，投影高斯会产生大量 tile–Gaussian 键值对。原始 3DGS 用 (3) 圆和其轴对齐包围盒枚举 tile：低不透明度高斯的有效区域被高估，细长椭圆的 AABB 又包含很多根本不相交的 tile，后续复制、排序和渲染都被放大。

FlashGS 取 (/255)。论文在 (_0) 时使用这一更紧的 opacity-aware 边界，否则回退到 (r=3)，避免边界反而大于 (3)。

随后它：

  • 用姿态感知的椭圆–tile 精确相交，减少假阳性键值对；
  • 通过代数化简避免在每条边上反复求昂贵的二次方程根；
  • 将相交测试与键值生成融合；
  • 小椭圆由单线程处理，大椭圆交给一个 warp 协作，以平衡不等长工作；
  • 按各 kernel 的计算/带宽特征重新组织流水线和内存访问。

局限

FlashGS 的目标是等价地加速光栅化，而不是改善训练数据或场景表示。收益依赖分辨率、高斯规模、重叠程度和 GPU；高度 CUDA 特化的实现也不天然适用于所有图形 API 与硬件。

论文：FlashGS: Efficient 3D Gaussian Splatting for Large-scale and High-resolution Rendering（CVPR 2025）

如何选择这些方法

  • 目标是表面几何：优先理解 2DGS。
  • 目标是用更少基元表达锐利不连续：关注 3D-HGS。
  • 目标是修复致密化与针状高斯：分别看 Pixel-GS 与 Spectral-GS。
  • 目标是在线定位和增量地图：看 GS-SLAM，并先明确传感器配置。
  • 目标是跨尺度抗混叠：看 Mip-Splatting。
  • 目标是移动视角的一致排序：看 StopThePop。
  • 目标是保持 alpha 合成语义并提速：看 FlashGS。
  • 目标是彻底取消排序：看 WSR，同时接受其非物理近似。
