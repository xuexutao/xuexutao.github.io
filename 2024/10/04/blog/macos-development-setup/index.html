临时设置 SOCKS5 代理

如果端口提供 SOCKS5，优先使用 socks5h：

socks5:// 通常在本机解析域名，socks5h:// 则把域名交给代理解析，可减少本地 DNS 泄漏和解析结果不一致。并非所有程序都读取 all_proxy 或支持 SOCKS；遇到问题应查对应工具文档，而不是混用协议。

HTTP 和 SOCKS 两组配置应按实际端口二选一。若确实同时设置，具体使用哪一个由客户端决定，排错反而更困难。

不要在普通 macOS 上继续机械执行官方 environment.yml，也不要把安装失败误判成 Conda 或 pip 问题。可行流程是：

  1. 在 Mac 上整理图片，并用 COLMAP CPU 流程验证稀疏模型；
  2. 把数据复制到配有受支持 NVIDIA GPU、驱动和 CUDA 工具链的 Linux/Windows 主机或云实例；
  3. 按官方仓库当前 README 建立环境、训练和渲染；
  4. 使用第三方 Metal/MPS 移植时，把它视为独立实现，单独核对功能、性能和输出兼容性。
