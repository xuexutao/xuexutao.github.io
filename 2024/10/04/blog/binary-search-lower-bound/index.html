问题定义

对一个按非递减顺序排列的数组 nums 和目标值 target，lower_bound 返回第一个满足 nums[i] >= target 的位置。如果所有元素都小于 target，返回 nums.size()。

这个定义自然处理重复元素：

  • nums = {1, 2, 2, 2, 4}、target = 2 时返回 1；
  • target = 3 时返回 4；
  • target = 5 时返回 5，即尾后位置。

前置条件是搜索区间已经按比较规则分区。对通常的升序数组，这意味着数组必须有序；若前置条件不成立，二分过程没有正确性保证。

为什么使用半开区间

搜索区间采用 [left, right)：

  • left 是仍可能成为答案的第一个位置；
  • right 是仍可能成为答案区间的尾后位置；
  • 初始值为 left = 0、right = nums.size()；
  • 当 left == right 时区间为空，答案已经确定。

半开区间无需为“空数组的最后一个下标”制造特殊值，也避免在无符号下标上计算 nums.size() - 1 导致下溢。

循环不变量

每轮循环开始时保持三个事实：

  1. [0, left) 中的元素都小于 target；
  2. [right, nums.size()) 中的元素都大于或等于 target；
  3. 第一个不小于 target 的位置仍在 [left, right] 中，其中尾后位置也可以是答案。

初始化时，前两个区间都为空，因此不变量成立。

  • 否则 mid 可能就是第一个合格位置，不能排除它，因此令 right = mid。

两种更新都严格缩小区间并保持不变量。循环结束时 left == right，该位置左侧都小于目标，从该位置起都不小于目标，所以它正是 lower_bound。

精确查找不能只返回 lower_bound 的位置，因为该位置可能是第一个大于目标的元素，也可能是尾后位置。正确步骤是：

  1. 先求 lower_bound；
  2. 检查位置没有越过末尾；
  3. 再检查该元素是否等于目标。

返回 std::optional<std::size_t> 可以明确区分“找到下标 0”和“没有找到”。

复杂度

对 std::vector：

  • 每轮把候选区间至少缩小一半；
  • 比较次数和运行时间均为 O(log n)；
  • 额外空间为 O(1)；
  • 使用 const std::vector<int>&，函数调用本身不会产生 O(n) 的数组复制。

标准库 std::lower_bound 只要求前向迭代器。它对所有合格迭代器都执行对数次比较，但如果迭代器不支持随机访问，移动迭代器的总步数可能是线性的。例如对 std::set 或 std::map，应优先调用容器自己的成员函数 lower_bound。

常见错误

把相等元素直接返回

遇到 nums[mid] == target 就返回，只能找到某一个重复元素，不能保证是第一个。lower_bound 在相等时必须继续收缩右边界。

混用闭区间与半开区间

初始化为 right = nums.size() 后，right 是尾后位置，循环条件应为 left < right，更新应为 right = mid。把它与闭区间写法中的 left <= right、right = mid - 1 混合，会造成越界或漏解。

忘记尾后位置

返回值可以等于 nums.size()。访问 nums[index] 之前必须先判断 index < nums.size()。

搜索未排序数组

二分查找依赖“谓词先真后假”或“先假后真”的单调分区。未排序数据不满足这个结构，即使某次测试碰巧返回正确结果，也不构成算法正确。

用值传递容器

把参数写成 std::vector<int> nums 会复制数组，使整个函数至少付出线性时间和空间成本，掩盖二分查找本身的对数复杂度。

与标准库语义对齐

C++17 的 std::lower_bound(first, last, value) 返回区间中第一个“不小于 value”的迭代器；若不存在则返回 last。标准要求区间相对于表达式 element < value 已经分区。完整排序是最常见、但比单次调用所需条件更强的保证。

手写版本适合学习循环不变量或处理特殊索引逻辑；生产代码没有额外需求时，应优先使用经过充分测试的 std::lower_bound。
