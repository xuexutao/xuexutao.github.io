固定提交有一个容易被摘要遗漏的顺序细节：densify_and_clone() 和 densify_and_split() 都会调用 densification_postfix()，后者将 max_radii2D 按新点数重建为零；最终的 big_points_vs = self.max_radii2D > max_screen_size 却在这两步之后计算。也就是说，在 54c035f 的这条直接调用路径中，不能把该表达式简单解读为一次有效的“按此前累计最大半径剪枝”。tmp_radii 虽然在拓扑变化期间保持了当前 radii 的对齐，但最终 screen-size 条件读取的仍是 max_radii2D。修改这一逻辑前应先写回归测试，而不是只替换变量名。

_prune_optimizer：为什么不能只切参数

函数的核心结构为：

这里有四个关键点。

1. Optimizer state 以 Parameter 对象为 Key

optimizer.state 不是简单按字符串 "xyz" 查找，而是以旧 Parameter 对象为 key。创建新 Parameter 后必须：

  1. 取出旧 key 下的 state；
  2. 删除旧 key；
  3. 替换 parameter group 中的引用；
  4. 把 state 挂到新 key。

否则 optimizer 会继续持有已经不在模型中的旧参数。

2. Adam 矩也按相同 Mask 裁剪

幸存高斯的参数、exp_avg 和 exp_avg_sq 必须保持同一行对应关系。Adam state 中类似 step 的标量状态不需要按点裁剪，源码会保留它。

3. 尚无 State 时仍要替换参数

Adam 在第一次有效 step 时才可能惰性创建 state。若 stored_state is None，函数只创建裁剪后的新 Parameter；后续 step 会为它初始化状态。

4. 返回值重新绑定模型字段

parameter group 已经更新，但 GaussianModel._xyz 等属性仍指向旧对象，所以函数按 group name 返回新参数，随后由 prune_points() 重新赋值。

新高斯如何进入 Adam

删除使用 _prune_optimizer()，追加则使用 cat_tensors_to_optimizer()。对每个 parameter group，它：

  1. 在第 0 维拼接旧参数和新参数；
  2. 给新行追加全零 exp_avg；
  3. 给新行追加全零 exp_avg_sq；
  4. 用拼接结果创建新 Parameter；
  5. 把旧 state 改挂到新 Parameter。

因此：

  • 老高斯保留 Adam 动量；
  • 新高斯从零动量开始；
  • 所有参数组的第 0 维仍严格对齐。

densification_postfix() 完成追加后，会重新创建全零的梯度累计、观测计数和历史最大屏幕半径，因为旧统计不再能直接对应新拓扑。

Topology 变更创建了新的 Parameter，当前 iteration 在旧 Parameter 上得到的普通训练梯度不会转移到新对象。因此发生增密/剪枝的那一轮，Gaussian optimizer 的下一次有效参数梯度来自后续重新 render 和 backward；幸存点的 Adam 历史矩则按上述逻辑得到保留。

Opacity Reset 也必须处理 Optimizer

reset_opacity() 不是原地修改 _opacity.data，而是：

  1. 将实际 opacity 截到不超过 0.01；
  2. 通过 inverse sigmoid 转回 logit；
  3. 调用 replace_tensor_to_optimizer()；
  4. 为新 opacity 参数创建全零 exp_avg 和 exp_avg_sq。

这表示 opacity reset 不仅改变参数值，也主动清空 opacity 的 Adam 动量，避免旧动量立即把参数推回重置前的状态。

初始提交与固定版本的差异

很多教程引用 2023-07-04 的初始提交：

与固定提交 54c035f 相比，和本文主链直接相关的差异包括：

  • 初始版 visibility_filter 是 radii > 0 的 bool mask；固定版返回 (radii > 0).nonzero() 的索引；
  • 初始版 densify_and_prune() 没有 radii 参数；
  • 初始版没有临时 tmp_radii，prune_points() 也不裁剪它；
  • 固定版在 clone/split 追加时同步追加 tmp_radii，并在父点删除和最终 prune 时同步裁剪；
  • 固定版还加入了 exposure、可选 depth regularization、anti-aliasing、Sparse Adam 等外围能力。

两版的核心思想没有变：按可见视图累计二维位置梯度，以平均梯度和世界尺度区分 clone/split，再同步修改模型参数、统计量和 Adam state。

复制旧教程代码到固定版时，最常见的问题是函数签名少了 radii，或新版 prune_points() 访问尚未创建的 tmp_radii。解决方法不是随意删除一行，而是先统一整个调用链所对应的 commit。
