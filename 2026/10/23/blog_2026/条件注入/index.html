条件注入：条件信息如何进入生成网络

在条件生成任务中（如条件 GAN、扩散模型、StyleGAN），如何把条件信息 （类别标签、文本、风格码、空间布局等）有效地注入网络，是一个核心设计问题。本文系统梳理主流的条件注入方法，并讨论它们的关系与适用场景。

1. FiLM：特征仿射调制

1.1 原理

FiLM（Feature-wise Linear Modulation）的核心思想：用一个条件向量 去逐通道地缩放和平移特征图。

1.2 FiLM 残差块

把 FiLM 嵌入残差块（Residual Block）就得到 FiLM 残差块，典型结构：

  1. 输入特征 经过卷积 + 归一化
  2. 条件 通过一个小网络生成
  3. 用 FiLM 调制特征
  4. 再过一层卷积

1.3 特点

  • 参数量极轻：MLP 从 映射到 维（ 和 各 ），远小于卷积本身
  • 不改变特征分布：只做缩放+偏移，不改变特征的均值/方差结构
  • 适合保留特征骨架的场景：条件控制方向，而非重建风格

2. AdaIN：自适应实例归一化

2.1 原理

与 FiLM 的关键区别：先做 Instance Normalization 再调制。

2.2 与 FiLM 的对比

维度 FiLM AdaIN
前置操作 无 InstanceNorm
对原分布的影响 保留 抹掉原有均值/方差
适用场景 条件控制（保留结构） 风格迁移（需要风格对齐）
代表工作 条件 CNN Karras et al. 2017

关键洞察：FiLM 和 AdaIN 表面相似，但 AdaIN 会先"洗掉"原有统计再重新赋予——所以 AdaIN 更适合风格迁移（需要抹掉内容风格），FiLM 更适合条件控制（保留特征结构，只调方向）。

3. Cross-Attention：交叉注意力

3.1 原理

条件不作为数值参数注入，而是作为 Key/Value 被特征"查询"：

  • 特征 作为 Query
  • 条件 作为 Key 和 Value
  • 注意力权重决定"从条件中取多少信息"

3.2 典型应用

  • Stable Diffusion：文本条件通过 Cross-Attention 注入 U-Net 的各个分辨率层
  • Transformer 条件生成：条件 token 和生成 token 做 full attention

3.3 优劣

  • 优势：能处理变长序列条件（文本、多模态），表达力最强
  • 代价：计算量 ，比 FiLM 贵几个数量级

4. Concatenation：通道拼接

4.1 原理

最朴素的方式：把条件广播到空间维度，和特征在通道维拼起来，让后续卷积自己学怎么用：

4.2 典型应用

  • ControlNet：输入条件（边缘图、深度图）concat 到 U-Net 的输入
  • U-Net 时间步注入：时间步嵌入 broadcast 后 concat 到每个 ResBlock 的输入

4.3 优劣

  • 优势：零额外设计，信息无损
  • 缺点：需要网络自己学"哪个通道是条件"，不如显式调制高效

8. Additive：加法注入

条件经映射后直接加到特征上。最简单的注入方式：

  • 位置编码：正弦/余弦位置编码加到 Transformer 输入
  • 时间步嵌入：扩散模型中时间步嵌入加到 U-Net 的 ResBlock 输入

9. HyperNetwork：超网络生成权重

9.1 原理

HyperNetwork 的核心思想：用一个"小网络"（HyperNetwork）根据条件生成"主网络"的权重参数。

其中 是 HyperNetwork， 是条件输入， 是动态生成的主网络权重。

9.2 变体

  • Partial HyperNetwork：只生成部分权重（如 BN 参数、最后 FC 层），避免参数量爆炸
  • LoRA-HyperNet：生成 LoRA 的低秩矩阵，实现条件化的参数高效微调
  • Conditional Weight Generation：直接生成整个卷积核（计算量大，较少用）

9.3 优劣

  • 优势：理论上表达力最强——条件可以完全决定网络行为
  • 缺点：参数量大、训练不稳定、难以优化；实际中多用于生成 LoRA/BN 参数等轻量场景

16. CFG：无分类器引导（推理时的条件增强）

16.1 原理

CFG（Classifier-Free Guidance）不是架构层面的注入方式，而是推理时的引导策略。它通过同时运行条件和无条件预测，放大条件的影响力：

  • ：无條件预测（ 置空）
  • ：引导强度（典型值 3~15）
  • ：被条件"拉偏"后的最终预测

16.2 本质理解

CFG 的核心是用条件方向和非条件方向的差作为"引导梯度"：

这等价于在每一步去噪时，沿"条件 vs 无条件"的差值方向额外推一步。 越大，生成结果越贴合条件，但多样性降低。

16.3 CFG 与架构注入的关系

维度 架构注入（FiLM/AdaIN/...） CFG
作用层面 模型结构 推理策略
作用时机 训练 + 推理 仅推理
是否需要额外训练 是（条件必须被网络学到） 否（只需模型支持无条件推理）
效果 让网络"能理解"条件 让网络"更听话"
代价 架构复杂度 每次推理需要 2× 前向（条件 + 无条件）

关键观点：CFG 和架构注入是互补的，不是替代关系。一个模型先用 FiLM/Cross-Attention 学会理解条件，再用 CFG 在推理时放大这个理解。Stable Diffusion 就是 Cross-Attention 注入 + CFG 引导的组合。

16.4 CFG 的变体

  • Dynamic CFG：不同时间步用不同 （高噪声时强引导，低噪声时弱引导）
  • Guidance Interval：只在部分时间步区间施加 CFG
  • Negative CFG：用负面提示（negative prompt）作为 替代无条件

17. 总结：怎么选

场景 推荐方法 理由
条件是单个向量（类别/时间步/风格码） FiLM 或 AdaLN 轻量、高效
条件是文本/序列 Cross-Attention 变长、语义丰富
条件是空间图（深度/分割/边缘） Concat 或 SPADE 保留空间信息
需要抹掉原有风格再重建 AdaIN 强制统计对齐
Transformer 架构 AdaLN 天然适配 LN 位置
推理时需要更强的条件控制 CFG 与架构注入互补
需要条件完全决定网络行为 HyperNetwork 理论表达力最强
多任务/多条件共享骨干 Conditional BN 轻量、易于实现
条件需要切换不同的"检测模式" Dynamic Convolution 动态核组合
参数高效的多条件微调 LoRA-style 低秩、可插拔
需要控制信息流入比例 Gated Fusion 门控机制灵活
风格迁移中的注意力控制 AdaAT 修改注意力分布
辅助增强其他注入方式 Adaptive Activation 极轻量，配合使用

一句话总结：架构注入解决"条件怎么进去"，CFG 解决"进去的条件怎么被更好地利用"。两者组合使用效果最佳。
