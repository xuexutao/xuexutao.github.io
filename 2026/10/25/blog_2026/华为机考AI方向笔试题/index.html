1.4 逻辑回归的损失选择

4、逻辑回归通常选用交叉熵而不是均方误差（MSE），最关键的理由是：

  • A. 交叉熵只能用于二分类
  • B. 逻辑回归搭配 MSE 时目标往往非凸，容易停在局部最优；交叉熵对应的目标是凸函数
  • C. 交叉熵的前向计算更快
  • D. MSE 无法作用于取值在 的概率输出

答案：B

解析： Sigmoid 输出与 MSE 组合时，目标函数可能出现非凸形状，优化更容易受到局部形态影响；交叉熵与逻辑回归组合后得到的目标函数是凸的，更适合稳定优化。交叉熵并不只能用于二分类，MSE 也可以作用于概率输出。

1.5 线性相关的定义

5、称一组向量线性相关，指的是：

  • A. 向量个数严格大于所在空间的维数
  • B. 该组中至少含有一个零向量
  • C. 存在一组不全为零的系数，使其线性组合等于零向量
  • D. 组内任意向量都能由其余向量线性表出

答案：C

解析： 线性相关的定义是存在一组不全为零的系数，使这些向量的线性组合等于零向量。A、B 只是某些充分条件，D 只有在特定向量组中才成立，不能作为一般定义。

2.5 预训练停训判据

10、预训练阶段做评估、决定是否停训时，下面哪一种做法最合理？

  • A. 验证集 Loss 一旦回升就立刻停训，以免过拟合
  • B. 只把训练 Loss 当判据，它不再下降就马上停
  • C. 为省算力只在全部训完后评估一次，过程中评测会明显拖慢进度
  • D. 定期在多样化下游任务（如常识推理、科学问答、代码补全）上做零样本评测，综合判断能力是否饱和

3. 单选题（第 11-15 题）

3.1 推理 OOM 的最有效改动

11、约 7B 参数的模型做 4-bit 量化，放在单卡 16GB 上，并发从 6 提到 16 后频繁 OOM。若只能改一项，哪项最有效？

  • A. 把 temperature 从 0.8 改成 0.1
  • B. 把 max_new_tokens 从 2048 改成 512
  • C. 调大 top_k
  • D. 加大 presence penalty

答案：B

解析： OOM 的直接原因是显存不足，而生成长度会直接影响 KV Cache 的大小。将 max_new_tokens 从 2048 降到 512 能显著缩短每个请求的缓存长度，并发升高时效果最直接。temperature、top_k 和 presence penalty 主要影响采样分布，不会明显降低 KV Cache 占用。

3.3 KV Cache 地址不连续的后果

13、优化 Attention Kernel 时，若 NPU/GPU 读 KV Cache 的地址不连续，通常会带来什么后果？

  • A. Tensor Core 无法使用
  • B. 模型精度下降
  • C. 内存访问无法合并，带宽被浪费
  • D. GPU 算力反而提升

答案：C

解析： KV Cache 地址碎片化或不连续时，线程访问难以合并成高效的内存事务，导致内存访问无法合并、带宽利用率下降。这通常不会直接改变模型精度，也不意味着 Tensor Core 一定无法使用。

3.4 稀疏线性方程组：直接法 vs 迭代法

14、解大规模稀疏线性方程组时，直接法（如 Cholesky）与迭代法（如共轭梯度）的主要取舍是：

  • A. 迭代法总是更精确
  • B. 迭代法不受条件数影响，解的质量更有保证
  • C. 直接法通常更稳，但内存与填充代价高；迭代法更省内存，却依赖预条件器与收敛性
  • D. 直接法处理不了非对称矩阵，迭代法在非对称情形上有天然优势

答案：C

解析： 直接法通常数值稳定性较好，但分解过程可能产生大量填充，带来较高内存和计算成本；迭代法内存开销相对较小，但效果依赖预条件器、条件数和收敛性。A、B 把两类方法的优缺点绝对化，D 也不成立。

3.5 CIoU Loss

15、目标检测（如 YOLO 系列）里常用 CIoU Loss 做定位损失。它相对 IoU 的主要增强是：

  • A. 同时纳入重叠面积、中心点距离以及宽高比
  • B. 只考虑分类误差
  • C. 只考虑中心点距离
  • D. 只考虑重叠面积

答案：A

解析： CIoU 在 IoU 重叠面积的基础上，还加入中心点距离惩罚和宽高比一致性惩罚，使预测框的位置和形状都能得到约束。其余选项只覆盖了部分因素。

4.2 推理显存的主要来源

17、大模型推理通常不做反向传播，显存仍常常捉襟见肘。下列哪些是推理显存紧张的主要来源？

  • A. 模型本身的参数量（Weights）十分庞大
  • B. 需要保存历史上全部请求的梯度
  • C. 随着生成变长而持续增长的 KV Cache
  • D. 前向计算中不可避免的激活值（如 Softmax 输出）峰值
  • E. 高并发、大 Batch Size 使上下文状态急剧膨胀

答案：A、C、D、E

解析： 推理显存主要由模型权重、KV Cache、前向计算所需的临时激活，以及高并发带来的多请求上下文状态共同占用。推理阶段通常不保存反向传播所需的历史梯度，因此 B 不属于主要来源。

4.3 梯度计算困难的情形

18、下列哪些情形会让梯度计算变得困难？

  • A. 训练时随机丢弃神经元
  • B. 参数共享（如 CNN 中的卷积核）
  • C. 激活函数采用了不可导的阶跃函数（Step Function）
  • D. 网络结构存在环路，不是 DAG

答案：C、D

解析： 阶跃函数在跳变点不可导，难以使用常规反向传播；网络存在环路时也不再是普通的有向无环计算图，梯度展开和计算会变得复杂。随机丢弃神经元和参数共享都可以通过现有反向传播机制处理。

4.4 大模型基础结构与训练细节

19、关于大模型的基础结构与训练细节，下列说法正确的有哪些？

  • A. Encoder-only 模型通常以因果语言模型（CLM）为预训练目标，而 Decoder-only 模型采用掩码语言模型（MLM）
  • B. 在 Encoder-Decoder 结构中，Encoder 的最终输出会作为 Decoder 交叉注意力层的 Key 和 Value
  • C. KV Cache 主要用于提升 Decoder 在推理阶段的效率，避免重复计算历史位置的 Key 和 Value
  • D. 无论 Encoder 还是 Decoder，通常都需要位置编码来引入序列顺序

答案：B、C、D

解析： Encoder-Decoder 模型中，Decoder 的交叉注意力会使用 Encoder 输出作为 Key 和 Value，B 正确。Decoder 推理时使用 KV Cache 保存历史 Key 和 Value，避免重复计算，C 正确。Encoder 和 Decoder 都需要某种位置编码来表达序列顺序，D 正确。A 把 CLM 和 MLM 的典型适用结构对调了。

4.5 常见分词方法

20、分词方式会同时影响效果和词表规模。下列哪些属于常见的分词方法（Tokenization）？

  • A. Word2Vec（词向量模型）
  • B. BPE（Byte Pair Encoding，字节对编码）
  • C. WordPiece（单词片段）
  • D. SentencePiece（句子片段）

答案：B、C、D

解析： BPE、WordPiece 和 SentencePiece 都是常见的子词分词方法。Word2Vec 是训练词向量的模型，不是分词算法，因此不选 A。

5.2 第 2 题：长序列 KV 缓存稀疏保留

5.2.1 题目描述

在大型语言模型的实时推理中，KV 缓存会随着序列变长而占用大量显存。为了缓解显存压力，需要在全局显存预算内对 KV 缓存进行稀疏保留：对每一层、每一个注意力头，选择重要 token 保留其 KV，不同层和不同头可以保留不同数量的 token。

选择时必须满足以下规则：

  1. 当前正在生成的 token 位置 必须保留，每层每个头都要保留位置 。
  2. 其他位置按照注意力分数从高到低进行全局排序，优先保留分数高的 token。
  3. 分数相同时，依次按照层索引、头索引、token 索引升序排列。
  4. 最终保留的 token 总数不能超过显存预算 。题目保证 不小于每层每头必须保留的当前位置数量。

具体做法是先从预算中扣除 个必须保留的位置，得到剩余预算；再对所有位置不等于 的注意力分数进行全局排序，选取前若干项。
